# FUERA DE TEMPORADA — iPhone 11 / 8811

Tercera página del proyecto, basada en el póster de manzana mordida y tipografía retro. El fondo y la tipografía se sirven como capas independientes para animar cada elemento.

El estado 3 muestra en grande `Tengo pila para rato` y debajo `Las organizaciones sin fines de lucro lo agradecen.` El regreso se realiza desde el enlace superior `De nuevo`.

Ejecutar desde esta carpeta:

```bash
PORT=8811 bash scripts/run.sh
```
