# FUERA DE TEMPORADA — iPhone 4 / 8804

Cuarta página del proyecto, basada en el póster verde **Susúrrame entre manzanas**. El fondo y la tipografía se sirven como capas independientes para animar cada elemento.

El estado 3 muestra en grande `Cerca tuyo sigo activo` y debajo una referencia a obras que usan Bluetooth para convertir la proximidad de los teléfonos en una imagen en tiempo real. El regreso se realiza desde el enlace superior `De nuevo`.

Ejecutar desde esta carpeta:

```bash
PORT=8804 bash scripts/run.sh
```
