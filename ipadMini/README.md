# FUERA DE TEMPORADA — iPad mini / 8888

Página del proyecto basada en el póster naranja **FROTAME / aún respondo**. El fondo y la tipografía se sirven como capas independientes para animar cada elemento.

El estado 3 muestra en grande `No sabés todo lo que aún te puedo enseñar` y debajo la frase breve `Los dispositivos descartados pueden volver a las escuelas para enseñar.` El regreso se realiza desde el enlace superior `De nuevo`.

Ejecutar desde esta carpeta:

```bash
PORT=8888 bash scripts/run.sh
```
