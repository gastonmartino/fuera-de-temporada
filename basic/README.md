# FUERA DE TEMPORADA — versión básica / iPad mini / 8899

Versión de máxima compatibilidad para Safari antiguo. Usa HTML clásico, CSS fijo y JavaScript ES5 mínimo. No incluye animaciones, transiciones, `clamp()`, `inset()`, flexbox, etiquetas HTML5 ni dependencias externas.

Desde la carpeta raíz del proyecto se levanta junto con los otros sitios:

```bash
bash run-all.sh
```

También puede ejecutarse sola desde esta carpeta:

```bash
python3 server.py --port 8899
```

La versión básica también conserva los tres estados y permite tocar toda la pantalla splash para avanzar.
